# Text-based-rpg
rpg text based story game that revolves around turn based combat that relies on user's own input
prototype for a larger future project that will include visuals and art, aswell as music and possible collaborations,will use unity or godot 

initial functions will be: 
1. npc dialogue with reactions depending to users input
2. turn based combat with visuals and sprites
3. stress and health
4. time functions to reverse time in ch 5
5. world building and added characters
6. complicated strategy
